Firebase

Conectado a kanbarter · Firestore + Storage.
Los datos se sincronizan en tiempo real entre todos tus dispositivos.

Acceso

?public=tasks — vista equipo (solo tareas)
?public=refs — vista refs (trabajo en conjunto)
?public=refs&client=bmw — vista cliente (solo esa marca, aprobadas/finalizadas, puede comentar). Cambiar bmw por byd/mini/motorrad.
Notas y semillas nunca son visibles en modo público. Ninguna vista pública tiene privacidad real a nivel de datos — solo oculta visualmente lo que no corresponde.

Google Calendar

Crea un proyecto en console.cloud.google.com → APIs → Google Calendar API → Credenciales → OAuth 2.0 Client ID (tipo "Web application"). Agregá http://localhost:3000 en "Authorized JavaScript origins".

Una vez configurado, al completar una tarea se creará un evento por cada sesión trabajada en tu Google Calendar.
